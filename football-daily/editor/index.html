FT အတည်ပြုပြီးမှ ပွဲပြီးဟု ရွေးပါ။ PDF ခန့်မှန်းဂိုးကို ရလဒ်အဖြစ် မဖြည့်ပါနှင့်။ မပြင်ထားသောပွဲများကို မူလအတိုင်း ထားပါမည်။

ထုတ်ဝေမည့်အကြောင်းအရာ

    Publish သည် data ကို GitHub တွင် တစ်ကြိမ်တည်းသိမ်းပြီး production sync ကို ခေါ်ပေးပါမည်။ Live deployment အောင်မြင်သည်အထိ အောက်တွင် အခြေအနေစစ်ပါ။
