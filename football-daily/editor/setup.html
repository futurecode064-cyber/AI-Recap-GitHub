Editor သို့ပြန်ရန်

GitHub ရေးသားခွင့် ချိတ်ဆက်ရန်

ChatGPT ၏ GitHub connection ကို website က ယူသုံး၍မရပါ။ မိမိပိုင် GitHub account မှ Fine-grained personal access token တစ်ခု ဖန်တီးပြီး Cloudflare encrypted Secret ထဲတွင်သာ ထည့်ရပါမည်။ Token ကို chat၊ public repository သို့မဟုတ် ဤ form ထဲ မထည့်ပါနှင့်။

  1. GitHub token setup ကိုဖွင့်ပါ။ Resource owner: futurecode064-cyber။ သက်တမ်းကို မိမိသတ်မှတ်ပြီး expiry မတိုင်မီ ပြန်ချိတ်ပါ။
  2. Only select repositories ကိုရွေးပြီး future-code-football-daily နှင့် AI-Recap-GitHub နှစ်ခုသာ ရွေးပါ။
  3. Repository permissions: Contents — Read and write၊ Actions — Read and write။ Workflows/Admin permission မလိုပါ။ ဤ token သည် ရွေးထားသော repo နှစ်ခုကို ရေးနိုင်ပြီး workflow ခေါ်နိုင်သောကြောင့် လျှို့ဝှက်ထားပါ။
  4. Token ဖန်တီးပြီး Cloudflare → Workers & Pages → future-code-football-daily → Settings → Variables and Secrets တွင် Production Secret အဖြစ် FCD_EDITOR_GITHUB_TOKEN အမည်ဖြင့် ထည့်ပါ။
  5. Secret ချိတ်ပြီး production ကို redeploy လုပ်ပါ။ ရှိပြီးသား FCD_MAIN_PASSWORD နှင့် FCD_SESSION_SECRET ကို ဆက်သုံးပါသည်။ Editor ကို မိမိ Owner Login ဖြင့်သာ ဝင်နိုင်ပါသည်။
  6. Editor ကိုပြန်ဖွင့်ပါ။ Draft ပြန်ယူ → စစ်ဆေးရန် → အတည်ပြုအကွက် → Publish ကိုနှိပ်ပါ။

ဖိုင်များကို GitHub တွင် သိမ်းပြီး production sync ကိုခေါ်ပါမည်။ Cloudflare deployment အချိန်ကြောင့် မိနစ်အနည်းငယ် ကြာနိုင်ပါသည်။ အခြေအနေတွင် “Live marker တွေ့ရှိ” ပြပြီးမှ brand စာမျက်နှာကို စစ်ပါ။

ယာယီပြဿနာဖြစ်လျှင်

Credential မချိတ်သေးလည်း Draft ဖိုင်သိမ်း/ပြန်ဖွင့်နိုင်ပါသည်။ Data သိမ်းပြီး production sync ပျက်လျှင် “သိမ်းပြီးသားကို Production ပြန်ပို့ရန်” ကိုနှိပ်ပါ။ GitHub data ပြိုင်ပြင်ထားလျှင် Draft ကို download သိမ်းပြီး Server data အသစ်နှင့် ပြန်နှိုင်းယှဉ်ပါ။ Guard ကိုပိတ်ခြင်း၊ token ကို public ဖိုင်တွင်သိမ်းခြင်း မပြုပါနှင့်။
