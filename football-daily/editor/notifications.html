Notification ခေါင်းစဉ်Notification စာသား ဒီမှာပေါ်ပါမယ်။

Notification ပို့ရန်

  1. APK များကို ရွေးပါ။
  2. ခေါင်းစဉ်၊ စာသား ဖြည့်ပါ။
  3. အတည်ပြုပြီး Send Notification နှိပ်ပါ။

ပို့ခြင်းအခြေအနေကို Send ခလုတ်အောက်မှာ ပြပေးပါမည်။

Notification မရောက်ပါက စစ်ရန်

APK အသစ်ကို Install လုပ်ပြီး ဖုန်း Settings တွင် Notification ကို Allow ဖွင့်ထားရန် လိုအပ်ပါသည်။ Firebase က ပို့ခြင်းကို လက်ခံထားသော်လည်း ဖုန်းတိုင်းဆီ ရောက်ကြောင်း အာမမခံနိုင်ပါ။ လက်ရှိ APK များတွင် App ဖွင့်ထားချိန် Manual Notification ပြသခြင်းကို ဖုန်းအစစ်ဖြင့် အတည်မပြုရသေးပါ။
