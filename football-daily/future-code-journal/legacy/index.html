THE LEGACY

ဘောလုံးသမိုင်း | ဒဏ္ဍာရီများနှင့် မမေ့နိုင်သော ဇာတ်ကြောင်းများ

ကစားသမားဘဝ၊ ကလပ်အသင်းသမိုင်း၊ သမိုင်းဝင်ပွဲစဉ်နှင့် ဘောလုံးလောကရဲ့ အမွေအနှစ်တွေကို သီးသန့်ဖတ်ရှုနိုင်ပါတယ်။ ဆောင်းပါးဟောင်းတွေကို မဖျက်ဘဲ နေ့စွဲ၊ ခေါင်းစဉ်နဲ့ အမျိုးအစားအလိုက် စုစည်းထားပါတယ်။

ဆောင်းပါးများ ဖတ်ယူနေသည်…
