# Future Code StockGuard v1.0.0

Offline-first Android inventory and sales manager for Myanmar small businesses.

## Included in v1.0.0
- Product catalog: name, category, barcode, buy/sell price, stock, low-stock threshold
- Offline barcode scanning with bundled ML Kit + CameraX
- Sales cart with atomic stock deduction
- Daily revenue, cost and gross profit dashboard
- Low-stock list
- CSV sales export
- Full JSON backup and restore via Android Storage Access Framework
- No account, no cloud backend, no Internet permission

Package: `com.futurecode.stockguard`
Minimum Android: 8.0 (API 26)
Target SDK: 35
