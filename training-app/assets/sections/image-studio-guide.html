FUTURE CODE AI STUDIO · OFFLINE LESSON

Future Code AI Image Studio အသုံးပြုနည်း

အောက်က သင်ခန်းစာတွေကို Internet မရှိလည်း ဖတ်နိုင်ပါတယ်။ AI Generate လုပ်တဲ့အခါမှာတော့ Internet၊ API Key နဲ့ Model ခွင့်ပြုချက် လိုပါတယ်။

01 · AI Image Studio ဆိုတာဘာလဲ

Text → New Image က စာသား Prompt ကနေ ပုံအသစ်ထုတ်ပါတယ်။ Photo Editing က မူရင်းပုံကို သတ်မှတ်ချက်အတိုင်း ပြင်ပြီး Product Poster က ပစ္စည်းကြော်ငြာပုံကို ဖန်တီးပါတယ်။

02 · API Key ယူရန်

Google AI Studio ကိုဖွင့်ပါ။ Gmail နဲ့ Sign in → Create API key → Project ရွေး → Copy လုပ်ပါ။ API Key ကို 01 Model & API → Gemini API Key Box မှာ Paste လုပ်ပါ။

03 · Image Model ရွေးရန်

Image Model (Nano Banana) Dropdown မှာ Nano Banana 2, Nano Banana 2 Lite, Nano Banana Pro စတဲ့ ကိုယ်သုံးနိုင်တဲ့ Model ကို ရွေးပါ။ Model အချို့မှာ Billing လိုပါတယ်။

04 · Mode ရွေးရန်

Text → New Image မှာ Reference Image မလိုပါ။ Photo Editing မှာ ပြင်ချင်တဲ့ပုံကို ထည့်ရမယ်။ Product Poster မှာ ပစ္စည်းပုံကို ထည့်ပြီး ကြော်ငြာရေးချင်တဲ့စာနဲ့ Style ကို Prompt မှာရေးပါ။

05 · ပုံအချိုး (Aspect Ratio)

1:1 က Facebook Post/Product Square, 9:16 က TikTok/Reels Story Vertical, 16:9 က YouTube Cover/Hero Image Landscape ဖြစ်ပါတယ်။

06 · Reference Image ကိုထည့်ရန်

Reference Image (Edit / Poster) မှာ PNG / JPG / WebP ပုံဖိုင်ကို ရွေးပါ။ လက်ရှိ Beta မှာ ပုံဖိုင် 8 MB ထက် မကြီးရပါ။ ကိုယ်ပိုင်ပုံ သို့မဟုတ် အသုံးပြုခွင့်ရှိတဲ့ပုံကိုသာ ထည့်ပါ။

07 · Prompt စနစ်တကျရေးရန်

Prompt မှာ Subject, Product, Background, Color, Lighting, Style, Text, Ratio ကို တိတိကျကျရေးပါ။ ဥပမာ: "Premium product poster for a white coffee mug, golden rim light, black background, elegant layout, no watermark".

08 · Template & Prompt Library

Premium Poster / Product Poster / Portrait / Social Media ခလုတ်တွေက အသင့်ရေးထားတဲ့ Prompt စာသားကို Prompt Box ထဲ ပေါင်းထည့်ပေးပါတယ်။ လိုသလို ပြန်ပြင်နိုင်ပါတယ်။

09 · Generate Image via Gemini

Model, Mode, Ratio, Prompt စစ်ပြီး ✦ Generate Image via Gemini ကိုနှိပ်ပါ။ ပြုလုပ်ချိန်က API Response/Network ပေါ်မူတည်ပါတယ်။ Quota ပြည့်၊ Model Access မရှိ သို့မဟုတ် Policy Block ဖြစ်လျှင် Error ပေါ်မယ်။

10 · Save Image

Generate အောင်မြင်ရင် Preview အောက်က ↓ Save Image ကိုနှိပ်ပြီး ပုံဖိုင်ကို သိမ်းပါ။ Copy Prompt က လက်ရှိ Prompt ကို Copy လုပ်ပေးပါတယ်။

11 · Image History & Credits ကို နားလည်ရန်

Image History က ဒီ Device/Browser ထဲမှာ အောင်မြင်ထားတဲ့ Generation တွေကို သိမ်းထားပါတယ်။ Successful Generations Count က Google API Credit Balance မဟုတ်ပါ။ Clear Device History နဲ့ ဖျက်နိုင်ပါတယ်။

12 · ပြဿနာဖြေရှင်းနည်း

Error တက်ရင် API Key မှန်/မမှန်၊ Model Access၊ Billing/Quota၊ Prompt နဲ့ File Type ကို စစ်ပါ။ Browser Storage ကိုဖျက်ရင် History ပျောက်နိုင်ပါတယ်။ AI Photo Editing မှာ မူရင်းပုံအသေးစိတ် မတူနိုင်လို့ Generate ပြီးတိုင်း စစ်ပါ။

⚠️ AI Model/Quota/သတ်မှတ်ချက်နဲ့ ဈေးနှုန်းတွေက Google ဘက်က ပြောင်းလဲနိုင်ပါတယ်။ API Key ကို လူအများနဲ့ မမျှဝေပါနဲ့။ Generated Content ကို စစ်ဆေးပြီးမှ ဖြန့်ဝေပါ။
