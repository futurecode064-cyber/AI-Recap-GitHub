Offline Guide
မူလ AppCreator24 APK ထဲက သင်ခန်းစာ Server Content နဲ့ Video Link အပြည့်အစုံကို ပြန်မရသေးပါ။ ဒီအပိုင်းက လက်ရှိ Beta အတွက် အသစ်ရေးထားတဲ့ Offline အခြေခံသင်ခန်းစာများ ဖြစ်ပါတယ်။ မူလသင်ခန်းစာတွေရဲ့ Link တွေကို သင်ပေးလိုက်ရင် အတိအကျ ပြန်ထည့်နိုင်ပါတယ်။
သင်ခန်းစာ 01 — AI Video အခြေခံ

AI Video ဆိုတာ Text Prompt၊ Image သို့မဟုတ် Video Reference ကို သုံးပြီး Video အသစ်ဖန်တီးတာဖြစ်ပါတယ်။ စတင်ဖို့ Video ရဲ့ ရည်ရွယ်ချက်၊ ကြာချိန်၊ ပုံစံ၊ Aspect Ratio ကို အရင်ဆုံးရွေးပါ။

  1. Video အမျိုးအစားကို ရွေးပါ — ကြော်ငြာ၊ သင်ခန်းစာ၊ ဇာတ်လမ်းတို။
  2. TikTok/Reels အတွက် 9:16၊ YouTube အတွက် 16:9 ကို အများဆုံးသုံးကြပါတယ်။
  3. ဇာတ်လမ်းကို Scene အလိုက်ခွဲရေးပါ။
  4. AI ထုတ်ပေးတဲ့အရာကို ပြန်ကြည့်ပြီး အမှားပါရင် Prompt ပြန်ပြင်ပါ။
သင်ခန်းစာ 02 — Character Consistency

Scene တစ်ခုကနေ နောက်တစ်ခုသို့ ဇာတ်ကောင်မျက်နှာ၊ အဝတ်အစား မပြောင်းဖို့ Character Sheet နဲ့ Reference Image ကို အသုံးပြုပါ။

  1. ဇာတ်ကောင်တစ်ယောက်စီရဲ့ အမည်၊ အသက်ဝန်းကျင်၊ ဆံပင်၊ အဝတ်အစား၊ အရောင်ကို သတ်မှတ်ပါ။
  2. Reference Image ကို အသုံးပြုခွင့်ရှိမှ တင်ပါ။
  3. Scene တိုင်းမှာ အခြေခံ Character Description တစ်ခုတည်းကို ပြန်သုံးပါ။
  4. Camera Angle, Emotion, Action တွေကို Scene အလိုက်သာ ပြောင်းပါ။
သင်ခန်းစာ 03 — Professional Video Prompt

Prompt တစ်ခုမှာ Subject + Action + Location + Camera + Lighting + Mood + Duration + Aspect Ratio တို့ကို ထည့်ပါ။

  1. Scene ရဲ့ အဓိကအကြောင်းအရာကို တစ်ကြောင်းရေးပါ။
  2. Camera movement: static, slow push-in, panning, tracking စသည်တို့ကို ရွေးပါ။
  3. Lighting/Style ကို သတ်မှတ်ပါ — warm cinematic, natural daylight, studio lighting။
  4. မလိုချင်တဲ့ စာသား၊ watermark၊ frame distortion တွေကို မထည့်ပေးဖို့ Prompt မှာ ဖော်ပြပါ။
သင်ခန်းစာ 04 — Voiceover / Subtitle

Video ပြုလုပ်ပြီးနောက် Script ကို မြန်မာလို ပြန်ရေးပါ။ Voiceover နဲ့ Subtitle ကို Timeline အလိုက် တိတိကျကျချိန်ပါ။

  1. ဇာတ်လမ်းပြောစာသားကို စာပိုဒ်တိုများအဖြစ် ခွဲပါ။
  2. TTS အသံထွက် အမှန်စစ်ပါ။ အမည်ခက်ခဲရင် အသံထွက်အလိုက် Script ပြင်ပါ။
  3. Subtitle တစ်ကြောင်းချင်းစီ ဖတ်ရလွယ်အောင် စာလုံးအရွယ်နဲ့ Background ကို သတ်မှတ်ပါ။
  4. နောက်ဆုံး Export ကို အသံနဲ့စာသားအတူစစ်ပြီးမှ Publish လုပ်ပါ။
သင်ခန်းစာ 05 — Video Editing & Export

Video Clip တွေကို အစီအစဉ်ကျကျ ချိတ်ဆက်၊ အပိုင်းပိုကို ဖြတ်ပြီး Music, Voice, Subtitle ကို ချိန်ပါ။

  1. Opening Hook ကို ပထမ 3–5 စက္ကန့်ထဲ ထည့်ပါ။
  2. Scene တစ်ခုနဲ့တစ်ခု အလွန်မြန်/နှေး မပြောင်းစေပါနဲ့။
  3. Background Music အသံက Voice ကို မဖုံးစေပါနဲ့။
  4. 1080p Video တစ်ခုကို မိမိဖုန်းနဲ့တကယ် Play လုပ်နိုင်သလား စစ်ပါ။
သင်ခန်းစာ 06 — Movie Recap Project လေ့ကျင့်ခြင်း

ကိုယ်ပိုင် Video သို့မဟုတ် ခွင့်ပြုချက်ရှိသော Public YouTube Video ကို စမ်းသုံးပါ။ AI ဖြင့် မြန်မာ Narration Script ထုတ်ပြီး Scene အချိန်၊ အသံထွက်၊ ပုံမှန်အစီအစဉ်ကို ပြန်ပြင်ပါ။

📖 Movie Recap အသုံးပြုနည်း

Future Code Movie Recap Website ရဲ့ Button တစ်ခုချင်း ဘာလုပ်တာလဲ၊ ဘယ်လိုအသုံးပြုရမလဲဆိုတာကို Internet မလိုဘဲ ဖတ်နိုင်ဖို့ ထည့်ထားပါတယ်။ အောက်က ခေါင်းစဉ်တွေကို နှိပ်ပြီး ဖွင့်ဖတ်ပါ။

ပထမဆုံး စမ်းသပ်ဖို့ မိမိပိုင် Video သို့မဟုတ် ပြန်လည်အသုံးပြုခွင့်ရှိတဲ့ Public YouTube Video ကို ပြင်ထားပါ။ အခြားသူပိုင် Movie Clip တွေကို အခွင့်မရှိဘဲ Download/Publish မလုပ်ပါနဲ့။
01 • App ထဲက Movie Recap ကို ဖွင့်နည်း
  1. အောက်ခြေ Menu ရဲ့ Movie Recap ကို နှိပ်ပါ။
  2. Movie Recap ကို App အတွင်းဖွင့်ရန် Button နှိပ်ပါ။ Web Studio ကို App အတွင်းမှာ ဖွင့်ပေးပါမယ်။
  3. Website အတွင်း Login / Payment / Google AI Request မှာ အခက်အခဲရှိရင် အပေါ်က Browser Button ကိုနှိပ်ပြီး Chrome မှာ သီးခြားဖွင့်ပါ။
  4. Website အတွက် Internet လိုပါတယ်။ ဒီသင်ခန်းစာကိုတော့ Offline ဖတ်နိုင်ပါတယ်။
02 • Public YouTube Link နဲ့ Video File ရွေးနည်း
  1. Step 01 · Media Import ကိုရှာပါ။
  2. YouTube Link Button ကိုရွေးရင် Public YouTube URL ထည့်နိုင်ပါတယ်။ PUBLIC YOUTUBE VIDEO URL Box မှာ Video Link Paste လုပ်ပါ။
  3. Load Link ↗ ကိုနှိပ်ပါ။ အောက်က Video Preview မှာ Video ပေါ်သလား ကြည့်ပါ။
  4. Local Video File Button ကိုရွေးရင် ဖုန်းထဲက Video File ရွေးနိုင်ပါတယ်။ File Upload/Choose Video နေရာကနေ Video ရွေးပါ။
  5. Local Video ကြီးရင် Upload/AI Request အချိန်ကြာနိုင်ပြီး Server Limit ရှိနိုင်ပါတယ်။ Internet မကောင်းရင် Public YouTube Link ကို အသုံးပြုနိုင်ပါတယ်။
03 • Video Title, Duration, Style နဲ့ Language
  1. Video ရဲ့ Movie Title ထည့်ခိုင်းရင် မှန်ကန်တဲ့ အမည်ကို ရေးပါ။ AI က Video မြင်ရတဲ့ အချက်ကိုပဲ အခြေခံဖို့ Title ကို အကူအညီအဖြစ်သာ သုံးပါတယ်။
  2. Recap Duration မှာ ထွက်လာစေချင်တဲ့ ဇာတ်လမ်းပြောကြာချိန်ကို ရွေးပါ။ 1/3/5/10 မိနစ် စသဖြင့် ရှိနိုင်ပါတယ်။
  3. Style မှာ Storytelling, Dramatic, Emotional စတဲ့ ဇာတ်လမ်းပြောပုံစံကို ရွေးပါ။
  4. Source Language မှာ မူရင်းဗီဒီယိုထဲက စကားပြောဘာသာကို ရွေးပါ။ မြန်မာ Narration Script ထုတ်ဖို့ Prompt က သီးခြားသတ်မှတ်ထားပါတယ်။
  5. Input Video တိုတယ်ဆိုရင် 10 မိနစ် Recap ကို အတင်းမသတ်မှတ်ပါနဲ့။ မမြင်ရတဲ့ ဇာတ်လမ်းကို AI က တီထွင်ရေးမိနိုင်ပါတယ်။
04 • Gemini API Key အခမဲ့ရယူပြီး ထည့်နည်း
  1. AI Connection ထဲက ❔ API ယူနည်း ကိုဖွင့်နိုင်ပါတယ်။
  2. Google AI Studio API Keys ကိုဖွင့်ပြီး ကိုယ်ပိုင် Google Account နဲ့ Sign in ဝင်ပါ။
  3. ရှိပြီးသား Key ရှိရင် Copy ယူပါ။ မရှိရင် Create API key နှိပ်ပြီး Project ရွေး/ဖန်တီးပါ။
  4. Key ကို Gemini API Key Box ထဲမှာ Paste လုပ်ပါ။ Show Button က ထည့်ထားတဲ့ Key ကို ခဏမြင်ရအောင် ပြပေးပါတယ်။ Public နေရာမှာ မဖွင့်ပါနဲ့။
  5. Free Tier က Model တိုင်း မရနိုင်ပါ။ Gemini Quota, Region, Billing ပြဿနာတွေရှိနိုင်ပါတယ်။ Free တစ်မျိုးတည်းလိုချင်ရင် Paid Billing မဖွင့်ပါနဲ့။
  6. API Key ကို Facebook၊ Telegram Group၊ Screenshot အဖြစ် မမျှဝေပါနဲ့။
05 • Generate Burmese Recap Button အသုံးပြုနည်း
  1. Step 02 · AI Story Engine ကိုဆင်းပါ။
  2. Video Link/File, API Key, Duration, Style တွေ အဆင်သင့်ဖြစ်မဖြစ် ပြန်စစ်ပါ။
  3. ✦ Generate Burmese Recap Button ကို နှိပ်ပါ။ Gemini က Video ရဲ့ Visual/Audio ကို Analyse လုပ်ပြီး မြန်မာလို Script နဲ့ Scene Timecode ထုတ်ရန် ကြိုးစားပါမယ်။
  4. အောက်က Progress Bar က Processing အခြေအနေကိုပြပါတယ်။ Video အရှည်နဲ့ Network အလိုက် ကြာနိုင်ပါတယ်။
  5. Cancel Button ပေါ်ရင် Request ရပ်ချင်တဲ့အခါ နှိပ်နိုင်ပါတယ်။
  6. ပြီးသွားရင် Step 03 · Scene & Script Editor ထဲမှာ Result ပေါ်ပါမယ်။ ဇာတ်ကောင်နာမည်နဲ့ ဇာတ်လမ်းအချက်တွေကို ကိုယ်တိုင် ပြန်စစ်ပါ။
06 • Gemini Safety Block / API Error ဖြေရှင်းနည်း
  1. Input blocked လို့ ပြရင် Google က Video ထဲက Frame တစ်ခုကို Content Policy အရ ပိတ်ထားတာ ဖြစ်နိုင်ပါတယ်။ API Key မှားတာနဲ့ မတူပါ။
  2. ဒီလိုဖြစ်ရင် Safety Filter ကို ကျော်မပို့ပါနဲ့။ အသုံးပြုခွင့်ရှိပြီး Policy နဲ့ ကိုက်ညီတဲ့ အခြား Video ရွေးနိုင်ပါတယ်။
  3. AI မရရင် ကိုယ်ပိုင် Script ရေးပြီး Scene Editor ဆက်သုံးရန် Button နှိပ်ပြီး Step 03 မှာ ကိုယ်တိုင်ရေးထားတဲ့ Script နဲ့ ဆက်လုပ်နိုင်ပါတယ်။
  4. 401/403 က Key သို့မဟုတ် Model Permission ပြဿနာ ဖြစ်နိုင်ပါတယ်။ 429 က Gemini quota/rate limit ဖြစ်နိုင်ပါတယ်။ Key/Model/Project ကို စစ်ပါ။
  5. Internet မကောင်းရင် Network ကိုပြန်စစ်ပါ။ လက်ရှိ Version မှာ Block တစ်ခုဖြစ်တိုင်း အလိုအလျောက် အောင်မြင်မယ်လို့ မကတိပေးနိုင်ပါဘူး။
07 • Full Script Box နဲ့ Script ပြန်ပြင်နည်း
  1. Step 03 · Editing Workspace ထဲက RECAPPER'S FULL SCRIPT Text Box မှာ AI က ထုတ်ပေးတဲ့ မြန်မာစာတစ်ကြောင်းချင်းစီ ပေါ်ပါမယ်။
  2. မမှန်တဲ့ ဇာတ်ကောင်နာမည်၊ အဖြစ်အပျက်၊ Ending ကို ပြန်ပြင်ပါ။
  3. စာကြောင်းတစ်ကြောင်းစီက Scene တစ်ခုကို ကိုယ်စားပြုပါတယ်။ ကြောင်းခွဲပြီး Scene ပိုထည့်နိုင်ပါတယ်။
  4. Apply Script to Scenes Button ကို နှိပ်ပြီး ပြင်ထားတဲ့ Full Script ကို Scene Card တွေထဲ ပြန်ချိတ်ပါ။
  5. Copy All Button က Script အားလုံးကို Copy လုပ်ပေးပါတယ်။ ↓ TXT Button က Script ကို Text File အဖြစ် Download ပေးပါတယ်။
  6. ↑ Import SRT က ရှိပြီးသား Subtitle File (.srt) ကို ပြန်ယူလာနိုင်ပါတယ်။
08 • Scene Timeline က Button တွေ အကုန်ရှင်းပြခြင်း
  1. SCENE TIMELINE ရဲ့ ＋ Button က Scene အသစ်ထည့်ပေးပါတယ်။
  2. Scene Card ထဲက Enable Check Box ကိုဖြုတ်ရင် အဲဒီ Scene ကို Render/Voice လုပ်တဲ့အခါ ချန်ထားနိုင်ပါတယ်။
  3. Scene Narration Textarea မှာ တစ် Scene စာသားကို သီးသန့်ပြင်နိုင်ပါတယ်။
  4. START · MM:SS နဲ့ END · MM:SS က မူရင်း Video ထဲက Clip စတင်/ဆုံးမယ့် အချိန်ပါ။ End က Start ထက် ကြီးရပါတယ်။
  5. ▶ Preview က Scene ရွေးထားတဲ့ Video အပိုင်းကို ကြိုကြည့်ပေးပါတယ်။ Video File/YouTube Preview အခြေအနေပေါ်မူတည်ပါတယ်။
  6. ↑ / ↓ Button တွေက Scene ကို အပေါ်/အောက် ရွှေ့ပါတယ်။ Duplicate က Scene ကို Copy ပွားပါတယ်။ Delete က Scene ကို ဖယ်ရှားပါတယ်။
  7. အချိန်မှားနေရင် Video Player နဲ့ ပြန်တိုက်စစ်ပြီး ပြင်ပါ။ AI Timecode တွေကို လုံးဝမှန်တယ်လို့ မယူဆပါနဲ့။
09 • Subtitle အရောင်၊ Size နဲ့ Video Ratio
  1. SUBTITLE TEXT COLOR က စာတန်းအရောင် ရွေးဖို့ပါ။
  2. SUBTITLE BACKGROUND က Subtitle နောက်ခံအရောင် ရွေးဖို့ပါ။
  3. SUBTITLE FONT SIZE Slider က စာတန်းကြီး/သေး ပြင်ဖို့ပါ။
  4. EXPORT RATIO မှာ 9:16 ကို TikTok/Reels အတွက်၊ 16:9 ကို YouTube အတွက်၊ 1:1 ကို Square Post အတွက် ရွေးနိုင်ပါတယ်။
  5. မြန်မာစာလုံးတွေ မတိကျရင် font/device/browser ပေါ်မူတည်ပါတယ်။ Export Preview မှာ မဖြစ်မနေ ပြန်စစ်ပါ။
10 • Burmese AI Voiceover ထုတ်နည်း
  1. Step 04 · Narration ကိုဆင်းပြီး Scene Script တွေ မှန်မမှန် အရင်ပြင်ပါ။
  2. Gemini Voice/TTS နဲ့ဆိုင်တဲ့ Generate Voice Button ကိုနှိပ်ရင် Cloud API က မြန်မာအသံ ဖန်တီးပေးရန် ကြိုးစားပါမယ်။ Model, Key, Quota နဲ့ Region Support လိုပါတယ်။
  3. Browser Voice Preview ရှိရင် ဖုန်း/Browser မှာ မြန်မာ TTS Voice သွင်းထားမှ အလုပ်လုပ်နိုင်ပါတယ်။
  4. အသံထွက်ပျက်နေတဲ့ နာမည်တွေကို စာသားပြန်ပြင်ပြီး Voice ထပ်ထုတ်ပါ။
  5. အသံဖိုင် ထွက်လာရင် ▶ Play နဲ့ စမ်းနားထောင်ပြီး ↓ WAV နဲ့ Audio ကို Download လုပ်ပါ။
  6. Free Quota မရှိတဲ့ Voice Model တွေမှာ Cloud API က Billing တောင်းနိုင်ပါတယ်။
11 • SRT, Video Export နဲ့ Download Button
  1. Step 05 · Export ကို ဆင်းပါ။
  2. Download SRT ရှိရင် Subtitle အချိန်နဲ့စာသားကို .srt File အဖြစ် သိမ်းပါ။
  3. ဗီဒီယို Clip ပါတဲ့ Output လိုချင်ရင် **အသုံးပြုခွင့်ရှိတဲ့ Local Video File** လိုအပ်ပါတယ်။ YouTube Link တစ်ခုတည်းကနေ မူရင်း Movie Clip တွေ Download မလုပ်ပေးပါ။
  4. Render Video နှိပ်မီ Ratio, Subtitle, Voiceover ရှိမရှိ ပြန်စစ်ပါ။
  5. Browser က MediaRecorder သုံးထားရင် WebM ဖိုင် ထွက်နိုင်ပါတယ်။ MP4 ကို Browser အားလုံးမှာ တိုက်ရိုက် Export အာမခံမရပါ။
  6. File Download ပြီးရင် Video ကို အစအဆုံး Play လုပ်ပြီး Audio Sync နဲ့ Subtitle ကို ပြန်စစ်ပါ။
12 • Save Project / ပြန်ဖွင့်နည်း
  1. Web Studio အပေါ်ဘက်က ↓ Save Project Button ကိုနှိပ်ပြီး လက်ရှိ Script/Scene Project File သိမ်းနိုင်ပါတယ်။
  2. Project File ထဲ API Key ကို မထည့်ပါနဲ့။ မျှဝေမီ ထိခိုက်နိုင်တဲ့ ကိုယ်ရေးအချက်အလက် မရှိအောင် စစ်ပါ။
  3. Browser Cache ဖျက်မိတာ၊ WebView က Reset ဖြစ်တာတို့မှာ Website ရဲ့ ခဏသိမ်းထားတဲ့ Data ပျောက်နိုင်ပါတယ်။ နောက်တစ်နေ့ဆက်လုပ်မယ်ဆို Project File ကို သီးသန့်သိမ်းပါ။
13 • Video Recap ကို Professional ဖြစ်အောင် ရေးနည်း
  1. အဖွင့် 2–3 ကြောင်းမှာ စိတ်ဝင်စားစရာ Hook ထည့်ပါ။ ဥပမာ “တစ်နေ့မှာ သူ့ဘဝကို ပြောင်းလဲမယ့် လျှို့ဝှက်ချက်တစ်ခု ပေါ်လာခဲ့တယ်…” (ဇာတ်ကားထဲမှာ တကယ်ပါမှသာ သုံးပါ)။
  2. အစပိုင်းမှာ ဇာတ်ကောင်မိတ်ဆက်၊ နောက်မှာ ပြဿနာ၊ အလယ်မှာ အဓိကဖြစ်ရပ်၊ နောက်ဆုံးမှာ Ending/Conclusion ကို စီပါ။
  3. အသံနှုန်းနဲ့ကိုက်အောင် Narration တိုတောင်းပြီး ဝါကျချိတ်ဆက်ကောင်းအောင်ရေးပါ။
  4. Script, Scene, Audio, Subtitle ကို သီးခြားစစ်ပြီး တစ်ကြိမ်စမ်းထုတ်၊ ပြင်ပြီး Final Export လုပ်ပါ။
