FUTURE CODE အားကစား ဂျာနယ် Android App

1. APK ကို Download လုပ်ပြီး Install နှိပ်ပါ။
2. ပထမဆုံး App ဖွင့်ချိန် အသိပေးချက်တောင်းပါက Allow နှိပ်ပါ။
3. ပုံ Download နှိပ်လျှင် Android 10 နှင့်အထက်တွင် Gallery / Pictures / FutureCode Sports Journal ထဲ သိမ်းပေးပါမည်။ Android 8–9 တွင် Save dialog မှ နေရာရွေးပါ။
4. အသိပေးချက် မရပါက App menu → အသိပေးချက် Settings နှင့် ဖုန်း Battery / Background ခွင့်များကို စစ်ပါ။ Force Stop လုပ်ထားလျှင် App ပြန်ဖွင့်ပါ။
5. ဗားရှင်းအသစ်ရလျှင် Update အသိပေးချက်ကို နှိပ်ပြီး Download ယူပါ။ ဖုန်းက တောင်းလျှင် Allow from this source ကို ဖွင့်ကာ Install ကို အတည်ပြုပါ။

ပွဲကြိုနှင့် ပေါက်ကြေး Noti သည် App ဖွင့်ချိန်နှင့် အနည်းဆုံး ၁၅ မိနစ်ခြား နောက်ခံစစ်ဆေးမှုကို အသုံးပြုပါသည်။ Battery နှင့် အင်တာနက်အခြေအနေကြောင့် နောက်ကျနိုင်ပါသည်။
