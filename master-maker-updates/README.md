# Future Code Master APK Maker update feed

Current: **0.4.0 / code 4**.

This isolated directory serves the Maker app update checker. `latest.json` is published after its versioned `.apk.b64` payload. The app decodes the payload and checks exact size, SHA-256, package, increasing version and the original signing certificate before opening the Android installer. Android asks the user to confirm installation.

Existing v0.3 installations need to install v0.4 once to receive this updater. The updater applies to Master APK Maker itself, not every app generated by students. App settings include automatic checks, Wi-Fi-only automatic download and notification permission. Android may delay background work.

For the next release: keep the same package/signing key, increase versionCode, test the signed APK, upload a new immutable `maker-N.apk.b64`, verify public decoded bytes, and replace `latest.json` last using its current blob SHA. Never publish keys or tokens. Source releases include scripts/prepare-release.py and UPDATE_RELEASE_GUIDE.md. Do not alter other apps or workflows in this repository.

0.4.0 includes 19 offline Burmese teacher-style lessons, practice checklists, learning notes/resume/font controls, course progress backup, and HTML app signing backup/version controls. Build/policy/browser checks passed; a physical-device update install has not yet been verified.
