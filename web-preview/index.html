01 ဗီဒီယို ရွေးချယ်ပါ

Public YouTube Video ကို AI က တိုက်ရိုက်ကြည့်ပြီး ဇာတ်လမ်းအကျဉ်းချုပ်ရေးပေးပါမယ်။ တခြား Website Link၊ Private/Unlisted Link မရပါ။

Browser မှာ 14 MB အောက် Local Video ကို Gemini API ထံ ပေးပို့ပြီး AI Analysis လုပ်နိုင်ပါသည်။ ပိုကြီးတဲ့ဖိုင်ကို Scene Export အတွက် ရွေးထားနိုင်ပေမဲ့ AI Analysis မလုပ်နိုင်သေးပါ။

Get Gemini API Key ↗Key ကို server/localStorage မှာ မသိမ်းပါ
သတိပြုရန် — Browser ကနေ Google API သို့ Key ကိုတိုက်ရိုက်ပို့ပါတယ်။ Public ကွန်ပျူတာမှာ Key မထည့်ပါနှင့်။ အသုံးပြုသူတစ်ဦးချင်းစီမှာ ကိုယ်ပိုင် Key လိုပါတယ်။ AI model အတွက် Quota/Charges ရှိနိုင်ပါတယ်။
