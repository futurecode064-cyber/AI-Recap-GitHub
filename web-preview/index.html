🔑 Gemini API Key ရယူနည်း (အဆင့်လိုက်)

Movie Recap AI လုပ်ဆောင်ချက်သုံးဖို့ Google Gemini API Key လိုပါတယ်။ ကိုယ်ပိုင် Google Account နဲ့ ကိုယ်တိုင်ယူနိုင်ပါတယ်။

  1. Google AI Studio ကို ဖွင့်ပါ။ အောက်က Google AI Studio ကိုသွားရန် ကိုနှိပ်ပါ။ aistudio.google.com/apikey ကိုရောက်သွားပါမယ်။
  2. Google Account နဲ့ Sign in ဝင်ပါ။ Gmail အကောင့်ရွေးပြီး လိုအပ်လာရင် Google ရဲ့ Terms of Service ကို ဖတ်ရှုပြီး သဘောတူပါ။
  3. API Keys စာမျက်နှာကိုသွားပါ။ Account အသစ်တွေမှာ Default Project နဲ့ API Key အသင့်ရှိနိုင်ပါတယ်။ ရှိနေပြီးသား Key ကို Copy ယူလို့ရပါတယ်။
  4. Key မရှိသေးရင် Create API key ကိုနှိပ်ပါ။ Project ရွေးခိုင်းရင် Default Project ကိုရွေးပါ။ မရှိသေးရင် Project အသစ်ဖန်တီးနိုင်ပါတယ်။ ပြီးရင် Key ကို Create လုပ်ပါ။
  5. API Key ကို Copy လုပ်ပါ။ အသစ်ရလာတဲ့ Key ဘေးမှာရှိတဲ့ Copy ခလုတ်ကို နှိပ်ပါ။ Key ကို Facebook Comment, Messenger Group, Screenshot တွေမှာ မတင်ပါနဲ့။
  6. ဒီ Movie Recap Web App ကို ပြန်လာပါ။ Key ထည့်ရန် ပြန်သွားမယ် ကိုနှိပ်ပြီး Gemini API Key ထည့်ရန် Box ထဲမှာ Paste လုပ်ပါ။
  7. စမ်းသုံးကြည့်ပါ။ Public YouTube Link ထည့်ပြီး Generate Burmese Recap ကိုနှိပ်ပါ။ API အသုံးပြုခွင့်၊ မော်ဒယ်နဲ့ Quota အခြေအနေပေါ်မူတည်ပြီး အောင်မြင်နိုင်ပါတယ်။

💰 အခကြေးငွေ သတိပြုရန်: Google ရဲ့ Free Tier ရနိုင်တဲ့ Project/Model တွေရှိပေမဲ့ Video Analysis နဲ့ Voice Model တိုင်း Free မဟုတ်နိုင်ပါဘူး။ Set up billing ဆိုပြီး Card တောင်းလာရင် Free အတွက် မဖြစ်မနေ ဖြည့်စရာမလိုပါ။ Billing ဖွင့်မယ်ဆိုရင် ကုန်ကျစရိတ်နဲ့ Quota ကိုအရင်စစ်ပါ။

❓ Create API key ခလုတ်မတွေ့ရင် / Key မထုတ်နိုင်ရင်

Google AI Studio ရဲ့ Dashboard → Projects ကိုသွားပြီး Project ရှိမရှိ စစ်ပါ။ မရှိသေးရင် Project အသစ်ဖန်တီးပါ။ Google Cloud Project ရှိပြီးသားဆို Import projects နဲ့ ထည့်နိုင်ပါတယ်။ Organization Account ဆိုရင် API Key Create လုပ်ခွင့် မရှိတာဖြစ်နိုင်ပါတယ်။

❓ API Key ထည့်ထားပေမဲ့ Error တက်ရင်

Key မှန်မမှန်၊ Space မပါအောင် Copy/Paste လုပ်ထားမထား၊ Project Quota ပြည့်မပြည့်၊ သုံးတဲ့ Gemini Model က သင့် Project အတွက် Available ဖြစ်မဖြစ် စစ်ပါ။ API Key ဟောင်း မလုပ်တော့ရင် AI Studio မှာ Key အသစ်ထုတ်ပါ။

🔐 API Key ကို လုံခြုံအောင် ဘယ်လိုထားမလဲ?

ကိုယ်ပိုင် Key ကို အများမြင်ရတဲ့နေရာမှာ မမျှဝေပါနဲ့။ ဒီ Web App ဟာ Browser ကနေ Google API ကို တိုက်ရိုက်ချိတ်တဲ့ စမ်းသပ် Version ဖြစ်တာကြောင့် Public Production Service မှာ Server-side Key Storage သုံးတာက ပိုလုံခြုံပါတယ်။ Key ပေါက်ကြားရင် Google AI Studio မှာ Revoke/Delete လုပ်ပြီး အသစ်ထုတ်ပါ။
