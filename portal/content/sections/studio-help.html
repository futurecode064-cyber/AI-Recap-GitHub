FUTURE CODE / STUDIO GUIDE

စတင်အသုံးပြုရန် လမ်းညွှန်

AI Image Studio

  1. Key Test နဲ့ မိမိရနိုင်တဲ့ model စာရင်းယူပါ။
  2. ပုံအသစ်၊ reference သို့မဟုတ် ပုံပြင် mode ကို ရွေးပါ။
  3. မူရင်းပုံ / ကိုယ်ပိုင်ပုံ တင်ပြီး အခန်းကဏ္ဍကို ရွေးပါ။
  4. ဘာတွေ ပြင်ချင်လဲ၊ ဘာတွေ ထိန်းထားချင်လဲကို သီးခြား ရေးပါ။
  5. စတိုင်၊ နောက်ခံ၊ အရောင်၊ အလင်း၊ camera၊ text၊ အချိုးအစားကို ဖြည့်ပါ။
  6. Prompt စုစည်းပြီး ပြန်စစ်၊ Generate နှိပ်ပါ။
  7. Result Preview မှာ ပုံသိမ်း သို့မဟုတ် ဒီပုံကို ထပ်ပြင်မည်ကို သုံးပါ။

Reference / ပုံပြင် mode မှာ ပုံလိုပါတယ်။ Model default resolution က model အများစုနဲ့ ပိုကိုက်ညီပါတယ်။

AI Video Maker

  1. Story၊ character၊ ဝတ်စုံ၊ setting၊ camera၊ အသံနဲ့ မပြောင်းစေချင်တာ ရေးပါ။
  2. API မသုံးဘဲ Prompt စုစည်းနိုင်၊ Manual Scene ထည့်နိုင်ပါတယ်။ AI Scene Plan လည်း ထုတ်နိုင်ပါတယ်။
  3. Text၊ Image၊ First/Last Frame သို့မဟုတ် Reference mode ရွေးပါ။
  4. Reference mode မှာ Veo 3.1 Standard၊ 8 sec၊ ပုံ 1–3 ပုံ သုံးပါ။ 1080p အတွက်လည်း 8 sec ရွေးပါ။
  5. Generate တစ်ကြိမ်သာ နှိပ်ပြီး Job Status စောင့်ပါ။ ချိတ်ဆက်မှု ပြတ်ရင် အရင် Job Status ပြန်စစ်ကို နှိပ်ပါ။
  6. Video ထွက်ရင် Preview အလိုအလျောက် ပြပါမယ်။ MP4 သိမ်းနိုင်၊ Video Editor သို့ ပို့နိုင်ပါတယ်။

မူရင်း video ပြင်ခြင်းက trim / crop / subtitle / audio / color edit ဖြစ်ပါတယ်။ ပုံကို animation ဖန်တီးခြင်းနဲ့ သီးခြားလုပ်ဆောင်ချက်ပါ။

Movie Recap / Video Editor

  1. အသုံးပြုခွင့်ရှိတဲ့ မူရင်း video ကို ဖုန်းထဲက တင်ပါ။ YouTube link က AI analysis အတွက်ပါ။ Final ထုတ်ဖို့ မူရင်းဖိုင် လိုပါတယ်။
  2. AI Recap ထုတ် သို့မဟုတ် Manual Scene / Script ထည့်ပါ။
  3. Scene တစ်ခုချင်း source start/end time၊ narration၊ subtitle၊ speed၊ အစီအစဉ်ကို ပြင်ပါ။ Playhead နေရာမှာ Scene ခွဲနိုင်ပါတယ်။
  4. Voice Sample နားထောင်ရွေးပြီး လိုတဲ့ Scene အသံကို ထုတ်ပါ။ ကိုယ်ပိုင် narration / music လည်း တင်နိုင်ပါတယ်။
  5. အချိုးအစား၊ crop၊ အရောင်၊ subtitle အရွယ်၊ title၊ volume ကို ပြင်ပါ။
  6. Final ထုတ်ပြီး Preview ကြည့်ပါ။ Preview နေရာက Scene ကို ပြန်ပြင်နှိပ်၊ controls ပြင်ပြီး ပြန်ထုတ်ပါ။
  7. Save နှိပ်၊ ဖုန်းရဲ့ ဖိုင်သိမ်းမယ့်နေရာ ရွေး၊ Save အတည်ပြုပါ။ ဖိုင်သိမ်းပြီး toast ပြပါမယ်။
  8. Device Draft က video နဲ့ edit တွေကို ထိန်းထားပေးပါတယ်။ JSON နဲ့ SRT ကိုလည်း သိမ်းနိုင်ပါတယ်။

AI Voice နဲ့ Scene ကြာချိန် ချိန်ထားရင် video speed ကို အသံကြာချိန်အလိုက် ချိန်ပါတယ်။ Visual ပြင်ရုံနဲ့ အသံကို ပြန်ထုတ်စရာ မလိုပါ။ Narration ပြောင်းရင် အဲဒီ Scene Voice ကို ပြန်ထုတ်ပါ။

ချိတ်ဆက်မှုနဲ့ Export

Google API Key က သင့် account ရဲ့ quota၊ region နဲ့ model access အပေါ် မူတည်ပါတယ်။ Veo API မှာ billing လိုနိုင်ပါတယ်။ API Key ကို project နဲ့ APK ထဲ မသိမ်းပါ။

ဖုန်းက MP4 encoder ပံ့ပိုးရင် MP4 ထုတ်ပြီး မပံ့ပိုးရင် WebM ထုတ်ပါတယ်။ Export အတွင်း ဒီစာမျက်နှာမှာ စောင့်ပါ။ 360p နဲ့ အတိုချုံးစမ်းပြီးမှ 720p / 1080p ပြန်ထုတ်နိုင်ပါတယ်။
