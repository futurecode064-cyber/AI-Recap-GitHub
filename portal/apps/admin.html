🌐 Websites / Web Apps အားလုံး — သီးခြား Statistics

Tracking တပ်ထားသော Website တွေ၏ View/Click မှတ်တမ်းများကို သီးခြားပြပါသည်။ Tracking မတပ်နိုင်သေးသော Website သို့မဟုတ် Live မစစ်နိုင်သေးသော Project တွေမှာ 0 အစား — ပြပါသည်။ GitHub Release Download နှင့် Button Click မတူပါ။

🎮 Game Play Sessions / Online Players ကို မူရင်းဂိမ်း Server သို့မဟုတ် Game Database ကနေ ချိတ်ဆက်ထားမှသာ ပြနိုင်ပါတယ်။ Website ဖွင့်ကြည့်ခြင်း၊ APK ဒေါင်းလုပ်ခလုတ်နှိပ်ခြင်းကို Game Play အဖြစ် မတွက်ထားပါ။ Game Play Tracking မရှိသေးရင် “မူရင်း Game Server Tracking မချိတ်ရသေး” လို့ ပြပါမယ်။

ဂိုးဇုံ Website ၏ ယခင် Cloudflare D1 download request မှတ်တမ်းကို ဂိုးဇုံ Owner Statistics ↗ မှ သီးခြားကြည့်နိုင်ပါသည်။ အောက်ပါ အချက်အလက်များမှာ Supabase မှ မှတ်တမ်းများ ဖြစ်ပါသည်။

📢 APK Notification ပို့ရန်

ရွေးထားသော APK ၏ Notification စနစ်ပါသည့် Version များက App ဖွင့်ချိန် သို့မဟုတ် နောက်ခံစစ်ဆေးချိန်မှာ ဖတ်ယူပါမည်။ Real-time FCM Push မဟုတ်ပါ။

ဂျာနယ် Website Views သည် ပွဲကြိုနှင့် ပေါက်ကြေး စာမျက်နှာများ၏ စာမျက်နှာဖွင့်မှုဖြစ်ပြီး နောက်ကြောင်းပြန်တွက်ချက်မရပါ။ APK Download Clicks သည် Download ပြီးဆုံးမှု သို့မဟုတ် Install လုပ်ပြီးသူအရေအတွက် မဟုတ်ပါ။ Goal Zone ၏ Cloudflare D1 Download Requests စာရင်းနှင့် တိုက်ရိုက်ပေါင်းမတွက်ထားပါ။ စနစ်စတင်တပ်ဆင်သည့်အချိန်မှစ၍သာ မှတ်တမ်းရှိပါသည်။ IP လိပ်စာနှင့် ဖုန်းနံပါတ်များကို မသိမ်းပါ။
